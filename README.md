API Autotests

Учебный проект по автоматизации тестирования REST API.

Проект создан для практики навыков QA: составление тест-кейсов, автоматизация API-сценариев, проверка позитивных и негативных сценариев и оформление результатов тестирования.

Цель проекта

Проверить основные сценарии работы с REST API пользователей и автоматизировать их с помощью Python и pytest.

Стек

- Python
- pytest
- requests
- REST API
- JSON
- Git / GitHub

Что протестировано

Сценарий| Метод| Проверка
Получение списка пользователей| GET| Status Code, наличие данных
Получение пользователя по ID| GET| Status Code, корректность ID
Получение несуществующего пользователя| GET| 404 Not Found
Фильтрация пользователей| GET| Query Parameters, количество результатов
Фильтрация по отсутствующему ID| GET| Пустой результат
Создание пользователя| POST| Status Code, данные ответа
Удаление пользователя| DELETE| Status Code
Создание пользователя без обязательного поля| POST| Негативный сценарий

Тест-кейсы

Перед автоматизацией сценарии были описаны в виде тест-кейсов.

Они находятся в:

"test-cases/test_cases.md"

Автотесты

Автотесты находятся в:

"test_api.py"

Для организации тестов используется pytest fixture из:

"conftest.py"

Проверяемые типы сценариев

Positive testing

Проверка корректных запросов:

- получение пользователей;
- получение пользователя по ID;
- создание пользователя;
- удаление пользователя;
- фильтрация данных.

Negative testing

Проверка некорректных сценариев:

- запрос несуществующего пользователя;
- фильтрация по отсутствующему ID;
- создание пользователя без обязательного поля.

Bug Report

Для найденного в рамках учебного сценария расхождения подготовлен bug report:

"bug-reports/bug_report.md"

В отчёте описаны:

- окружение;
- шаги воспроизведения;
- ожидаемый результат;
- фактический результат;
- Severity;
- Priority;
- влияние дефекта;
- рекомендация по исправлению.

Запуск проекта

Клонировать репозиторий:

git clone https://github.com/kurlongy/api-autotests.git

Перейти в папку проекта:

cd api-autotests

Установить зависимости:

pip install -r requirements.txt

Запустить тесты:

pytest -v

Что демонстрирует проект

В проекте отработаны следующие навыки:

- составление тест-кейсов;
- анализ ожидаемого поведения API;
- отправка HTTP-запросов;
- работа с GET, POST и DELETE;
- работа с query parameters;
- проверка HTTP status codes;
- проверка JSON-ответов;
- positive testing;
- negative testing;
- автоматизация тестов с pytest;
- использование pytest fixtures;
- оформление bug report;
- работа с Git и GitHub.

Проект является учебным и не представляет коммерческий опыт автоматизации тестирования.
