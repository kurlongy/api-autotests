API Autotests

Небольшой учебный проект по автоматизации API-тестирования на Python.

Цель проекта

Автоматизировать проверку основных сценариев работы REST API пользователей: получение данных, фильтрация, создание и удаление пользователей, а также обработка ситуаций, когда данные не найдены.

В качестве тестового API используется JSONPlaceholder — публичный REST API для тестирования и прототипирования.

Инструменты

- Python
- pytest
- requests
- REST API
- JSON
- HTTP-методы GET, POST, DELETE

Что тестируется

GET

- получение списка пользователей;
- получение конкретного пользователя;
- фильтрация пользователей по ID;
- запрос несуществующего пользователя;
- фильтрация по ID, которого нет.

POST

- создание нового пользователя;
- проверка статус-кода;
- проверка переданных данных в ответе.

DELETE

- удаление пользователя;
- проверка успешного выполнения операции.

Покрытые сценарии

Тест| Сценарий| Проверка
"test_users"| Получение списка пользователей| HTTP 200, список не пустой
"test_user"| Получение пользователя по ID| HTTP 200, корректный ID
"test_user_not_found"| Запрос несуществующего пользователя| HTTP 404
"test_create_user"| Создание пользователя| HTTP 201, корректные данные
"test_delete_user"| Удаление пользователя| HTTP 200
"test_filter_users_by_id"| Фильтрация по ID| HTTP 200, найден один пользователь
"test_filter_users_by_nonexistent_id"| Фильтрация по отсутствующему ID| HTTP 200, пустой список

Как запустить проект

Создать виртуальное окружение:

python -m venv .venv

Активировать его в Windows:

.venv\Scripts\activate

Установить зависимости:

pip install pytest requests

Запустить тесты:

pytest -v

Результат

Все тесты должны завершиться успешно:

7 passed

Что демонстрирует проект

Проект демонстрирует базовые навыки API-тестирования:

- отправка HTTP-запросов;
- работа с GET, POST и DELETE;
- использование query-параметров;
- проверка HTTP status codes;
- проверка JSON-ответов;
- позитивные и негативные тестовые сценарии;
- автоматический запуск набора тестов с помощью pytest.
