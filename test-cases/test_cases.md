API Test Cases

TC-001 — Получение списка пользователей

Цель: проверить получение списка пользователей.

Шаги:

1. Отправить GET-запрос на "/users".
2. Получить ответ от API.

Ожидаемый результат:

- HTTP status code = 200.
- Ответ содержит список пользователей.
- Список не пустой.

TC-006 — Создание пользователя

Цель: проверить создание нового пользователя.

Шаги:

1. Отправить POST-запрос на "/users".
2. Передать имя, username и email.
3. Получить ответ от API.

Ожидаемый результат:

- HTTP status code = 201.
- Ответ содержит переданные данные пользователя.
- Имя, username и email соответствуют отправленным значениям.

TC-008 — Создание пользователя без обязательного поля

Цель: проверить валидацию обязательных данных при создании пользователя.

Шаги:

1. Отправить POST-запрос на "/users".
2. Передать "name" и "username".
3. Не передавать "email".

Ожидаемый результат:

- API возвращает "400 Bad Request".
- Пользователь не создаётся.
- В ответе указано, какое поле отсутствует.

Автоматизация:
"test_create_user_without_email()"

Результат проверки:
Тест используется как негативный сценарий для проверки валидации входных данных.
